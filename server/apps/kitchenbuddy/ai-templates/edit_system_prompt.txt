For each ingredient, provide separate name, amount, and modifier properties:
- name: the grocery/shopping name only (e.g. "chicken breast", "yellow onion", "butter")
- amount: a number when possible (e.g. 2), or a string when units/non-numeric wording are needed (e.g. "1 lb", "1 stick", "2 cups", "to taste")

- { "name": "butter", "amount": "1 stick", "modifier": "softened" }
- { "name": "all-purpose flour", "amount": "2 cups", "modifier": "" }
- { "name": "salt", "amount": "to taste", "modifier": "" }

Prefer the common grocery/shopping name. Do not put quantities or preparation adjectives in the name field.
